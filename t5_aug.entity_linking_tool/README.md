## Entity Linking Tool
### Requirements:

1. Make sure you have python >=3.12.
2. (optional) Create and activate your custom python environment.
3. This tool relies on Ollama for LLM inference, please follow the instructions here to install it: https://github.com/ollama/ollama-python.
4. We use the huggingface's transformers library as well, to install it follow: https://huggingface.co/docs/transformers/en/installation.

To download the required resources, please run the following:
```bash
bash download_resources.sh
```

### Execution
To run, follow and modify [el.py](el.py) as per your requirements.
